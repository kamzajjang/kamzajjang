## 📂 Featured Projects

### 🚶 누구에게나 15분인가 | True 15-Minute City Analysis

**부산의 지형과 고령자 보행속도를 반영한 의료 접근성 분석**

성인 평지 기준으로 계산되는 '15분 생활권'이 산복도로 지형과  
60세 이상 보행속도를 반영하면 얼마나 달라지는지 측정하고,  
데이터 기반 정책 우선지역을 도출한 부산 Big Data 활용 대회 개인 분석 프로젝트입니다.

**My Role**

- 공공데이터 6종(생활인구, 병의원·약국, 버스정류소, DEM, 행정동 경계) 수집·정제 파이프라인 구축
- OSM 보행 네트워크 구축 및 경사·고도 반영 이동비용 모델링
- Dijkstra 기반 시설 접근성 계산 및 공간 분석
- 속도·격자·DEM 강건성·민감도 검증 및 정책 우선지역 도출
- 분석 보고서·인터랙티브 지도·시각화 자료 작성

`Python` `GeoPandas` `NetworkX` `OSMnx` `Spatial Analysis`
