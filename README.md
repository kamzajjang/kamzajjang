## 👋 About Me

현재 **데이터 분석가**를 목표로 R, SQL, Python을 중심으로 역량을 쌓고 있습니다.

특히 **공공데이터와 헬스케어·바이오 데이터 분석**에 관심이 있으며,  
단순히 데이터를 시각화하는 데서 끝나지 않고  
**문제를 정의하고, 분석 결과를 실제 활용 가능한 인사이트로 연결하는 과정**을 중요하게 생각합니다.

서비스 개발 프로젝트 경험을 통해  
데이터가 실제 사용자 경험과 서비스에 어떻게 연결되는지도 함께 고민해왔습니다.
